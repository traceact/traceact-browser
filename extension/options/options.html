Which sites get tracked

Type a domain the way you'd say it: myapp.com or 127.0.0.1:3000. No https:// needed. A bare domain covers its subdomains and every port; adding a port pins it to that one app.

    Redaction

    Turning this off captures typed text for ordinary fields. Passwords, card numbers, one-time codes, and fields named like a credential are still never captured, and credential-shaped values are still masked.

    Credential-shaped values (tokens, keys, JWTs, password fields) are masked before anything reaches disk, in every mode.
